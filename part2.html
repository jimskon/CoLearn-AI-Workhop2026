The Interface

What You'll See in the Platform

coLearn-AI presents one question at a time. The group reads it together, discusses, and the Spokesperson types the response. Understanding the interface before you start makes the activity run smoother.

The Submission Loop

Every question follows the same cycle regardless of question type:

💬

Discuss

Group reads the question, examines any code, and talks it through. No one types yet.

⌨️

Respond

Spokesperson types the agreed answer: text, code, or filled-in table cells. Quality Control reads it aloud.

🤖

AI Evaluates

The AI responds with one of three outcomes: Accept, Nudge, or Flag. No grades - just a prompt to think further.

🔄

Advance or Revise

Accepted? Next question. Nudged or flagged? Discuss the AI's question and revise. You have up to 3 retries.

The Three AI Responses

✅ Accept

The submission meets the requirement for this question. The group advances to the next question. This success is recorded in the epistemic trace.

💬 Nudge

The response is on the right track but is missing something or is incomplete. The AI asks one focused question pointing at what to reconsider. Discuss it among yourselves before revising.

⚠️ Flag & Re-try

The response misses the key requirement for this question. The AI flags it and invites the group to try again. You can retry up to 3 times total.

The AI will not give you the answer. Its job is to ask questions, not to teach. If the AI nudges your group, the goal is to resolve it through group discussion - not by rephrasing the same answer or asking the AI more questions.

B

Python Code Editor - Write or edit Python code

Python

A live Python code editor. The group can type, run, and iterate on code directly in the browser. The Spokesperson makes edits; the group watches and discusses before submitting.

coLearn-AI - Workshop Sampler
Section 2 · Question 2
Rewrite the loop below using range() so it prints the same values (5, 10, 15, 20, 25, 30).
for value in [5, 10, 15, 20, 25, 30]: print(value, end=" ")
# Edit the code here - run it to check for value in range(5, 31, 5): print(value, end=" ")
Submit →
✅ Accepted
Your range(5, 31, 5) generates exactly 5, 10, 15, 20, 25, and 30. Correct - and more maintainable than the original literal list.

Run the code before submitting. The output appears below the editor so you can check your work.

C

Python Turtle - Graphical programming

Python Turtle

A Python code editor with a live Turtle graphics canvas. Code runs immediately and the drawing appears in the canvas on the right. The group writes code and discusses what it draws before submitting.

coLearn-AI - Workshop Sampler
Section 3 · Question 3
Use a for loop to draw a filled square with side length 100. Choose any fill color you like.
import turtle t = turtle.Turtle() t.speed(0) for i in range(20): for _ in range(4): t.forward(100) t.left(90) t.left(18)
▢ Canvas: filled blue square appears here
Submit →
💬 Nudge
An outer loop running 20 times with an 18° rotation between squares produces the starburst rosette. The pattern emerges from the geometry - 20 × 18° = 360°.

The drawing appears instantly as you run. Experiment freely - the canvas resets each run.

D

C++ Code Editor - Write C++ in the browser

C++

A C++ code editor with a terminal-style output panel. Works the same as the Python editor: write, run, see output, discuss, submit.

coLearn-AI - Workshop Sampler
Section 4 · Question 4
Write a C++ for loop that prints the odd numbers from 1 through 19, one per line. Use cout for output. Include the necessary #include and main().
double target = 2.0; double low = 0.0, high = target; double mid = 0.0; while (high - low > 0.0001) { mid = (low + high) / 2.0; if (mid * mid < target) low = mid; else high = mid; } cout << "Bisection: " << mid << endl; cout << "sqrt(2): " << sqrt(target) << endl;
$ run
Bisection: 1.41422
sqrt(2): 1.41421
exit 0
Submit →
✅ Accepted
Correct bisection: low and high initialized to 0 and target, mid computed each iteration, and one bound updated based on mid*mid vs. target. Accurate to four decimal places.

The browser compiles and runs C++ - no IDE needed. Standard library functions all work.

For Loops - Workshop Sampler

This activity is designed to give you a complete tour of the platform's question types in one compact session. It covers the same concept - counted iteration - in five different forms. Work through each question in order as a group.

Activity overview

Q Type Task
1 Text What do you enjoy most about teaching computer science?
2 Text In your own words, explain the purpose of a loop - what problem does it solve?
3 Python Rewrite a literal-list loop using range(5, 31, 5)

5 C++ Rewrite a step-search for √2 using bisection (high − low < 0.0001)
6 Reflection Multiple-choice: which question type gave your group the most productive discussion?

What to Notice As You Work

🔄 The Rotation

A new Spokesperson takes the keyboard each question. Notice how this changes who speaks up and who stays quiet compared to a typical unstructured group task.

💬 When You're Nudged

Don't ask the AI a follow-up question. Resist that reflex. The nudge is a question for your group - discuss what it's pointing at, and try to resolve it yourselves.

📜 The Epistemic Trace

A trace panel on the side records every submission, every AI response, every revision. Watch it grow. This is what your instructor sees in real time.

🌐 Multiple Languages

Notice how the platform switches from Python to Turtle to C++ to a table - same platform, same AI, different modes. Consider which type fits which pedagogical goal.
