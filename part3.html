Activity Design & Implementation

⏱ 60 minutes 1:10 – 2:10 You are now the author
Your role just changed. You are no longer a student. You are now designing an activity for your students. By the end of this hour you will have 2–3 authored questions with working feedback prompts and sample responses, tested live in the platform.
Architecture

Four Layers of AI Guidance

Every AI response a student sees is shaped by four layers of guidance stacked on top of each other. Layers 0–2 are context. Layer 3 is what you craft — it is what actually shapes the scaffolding for each individual question.

  • 0
    Platform Guidance

    Always on. Set by coLearn-AI, invisible to instructors. Core rules: nudge, never solve; match student language; one focused question at a time.

  • 1
    Class Guidance

    Set once per course by the instructor. Establishes the teaching contract: accept engagement, one nudge at a time, never list failures, stay in scope for this class.

  • 2
    Activity Guidance

    Set per activity. Teaching style, hint threshold, topic scope. Applies to every question in the activity.

  • 3
    Question-Level Guidance (your main job)

    Set per question. Two pieces: a feedback prompt (invisible to students) that tells the AI exactly what to accept or push back on, and a sample response (not shown to students) that calibrates what correct looks like. Together they drive all three possible AI responses for this question.

Key insight You don't write the AI's replies. You write the criteria the AI uses to decide how to reply. One precise feedback prompt plus one or two sample responses is enough to control Accept, Nudge, and Flag behavior for a question.
Layer 3 Deep Dive

Writing Feedback Prompts & Sample Responses

The Feedback Prompt

The feedback prompt is invisible to students. It tells the AI the one criterion that determines whether a submission is accepted or pushed back on. One criterion only. Compound criteria lead to confusing nudges.

The feedback prompt answers this question: "What specifically must be true for this group's response to be accepted — and what is the one thing to ask about if it's not?"

The Sample Response

The sample response is not shown to students. It calibrates the AI's sense of what a correct answer looks like, so it can recognize equivalents — different variable names, different but valid range arguments, alternate valid code structures.

Worked Examples

Layer 3 in Practice

Python CS1 — For Loops with range()

Question: Rewrite the loop below using range() so it prints the same values.
for value in [3, 6, 9, 12, 15, 18]: print(value, end=" ")
Feedback Prompt (invisible to students)

"Require a for loop with range() that generates 3, 6, 9, 12, 15, and 18. Ignore minor spacing differences."

✅ range(3, 19, 3) → accept
💬 range(3, 18, 3) → nudge: "Does this include 18?"
⚠️ [3,6,9…] → flag: "use range() instead"
Sample Response (not shown to students)
for value in range(3, 19, 3): print(value, end=" ")

The AI uses this to recognise equivalent correct answers — different variable names, whitespace, alternate valid range arguments.

Python CS1 — Turtle Graphics & Loops

Question: Use a for loop to draw a regular hexagon (6 sides of length 80). Fill it with blue.
import turtle t = turtle.Turtle() # your code here
Feedback Prompt

"Require a for loop that runs exactly 6 times, calls t.forward(80) and t.left(60) (or t.right(300)) inside, and uses t.fillcolor/t.begin_fill/t.end_fill for blue. Accept any variable name for the turtle."

Sample Response
t.fillcolor("blue") t.begin_fill() for _ in range(6): t.forward(80) t.left(60) t.end_fill()

C++ CS1 — For Loops & Accumulation

Question: Write a C++ for loop that reads 10 integers from the user and prints their average. What type should the running total be?
Feedback Prompt

"Require a for loop that iterates exactly 10 times, reads an integer inside the loop, accumulates a running sum, and divides by 10 to produce the average. Accept double or float for the total; push back on integer division that truncates the result."

Sample Response
double total = 0; int val; for (int i = 0; i < 10; i++) { cin >> val; total += val; } cout << total / 10 << endl;
Authoring Principles

Rules for Writing Good Layer 3 Guidance

One criterion per feedback prompt

Pick the single most important thing that distinguishes a correct response from an incorrect one. If you find yourself writing "and" in the feedback prompt, split it into two questions.

The nudge question, not the answer

Phrase the feedback prompt so the AI will ask about the missing piece rather than state it. "Does range(3, 18, 3) include 18?" — not "The stop value is excluded."

Sample responses show equivalence

Provide the most natural correct answer. The AI uses it to recognize equivalents — different but valid code. You can include 2–3 variants if the question has multiple correct forms.

Write the trace you want to see

Work backwards: what reasoning path do you want the epistemic trace to reveal? Design the question and guidance to make that reasoning visible.

Your Turn 40 min

Author Your Own Activity

Working in the same groups as Part 2, design a short activity (2–3 questions) for a topic you teach. Use the authoring tool in coLearn-AI to enter your questions, feedback prompts, and sample responses — then test them.

Step 1 — Choose a Topic (5 min)

Pick something from one of your own courses. Good candidates for a first activity:

Python CS1 Ideas

  • While loops & sentinel values
  • List indexing and slicing
  • Function definition and return values
  • String methods and iteration
  • Nested loops (multiplication table)

Python Turtle Ideas

  • Drawing polygons with loops
  • Spirals using step changes
  • Color lists and iteration
  • Recursive tree (if comfortable)

C++ CS1 Ideas

  • for / while loop basics
  • Array declaration and traversal
  • Function with pass-by-reference
  • Struct definition and member access

Data Structures Ideas

  • Linked list traversal (Python or C++)
  • Stack push/pop trace
  • Binary search — loop invariant
  • Recursive base and recursive case

Step 2 — Write 2–3 Questions (10 min)

For each question, fill in the template below before entering anything into the platform. This forces you to think through the pedagogy first.

Question N

Question text (shown to students):
What does this code do? / Write code that... / Predict the output...

Code or context (if any):
paste code here

Feedback Prompt (one criterion, invisible to students):
Require... Accept... Push back on... Ask about...

Sample Response (correct answer, not shown to students):
paste your correct answer here

What reasoning should the trace reveal?
e.g. "whether the group predicted the off-by-one before running the code"

Step 3 — Enter into the Authoring Tool (15 min)

  1. Log in to colearn-ai.com and navigate to the Authoring section (facilitator will demonstrate).
  2. Create a new activity. Set a title and select "Python" or "C++" as the language.
  3. Enter your Activity Guidance (Layer 2): 2–3 sentences describing the teaching style and what the AI should emphasize for this activity.
  4. Add each question in order. For each: enter the question text, the feedback prompt, and the sample response.
  5. Preview the activity to see the student view.

Step 4 — Test It (10 min)

One group member takes the student role and submits test responses — including some that should be nudged and some that should be flagged. Check that the AI responds as you intended. Adjust the feedback prompt if the AI is too permissive or too strict.

Common authoring pitfalls
  • Feedback prompt is too vague → AI accepts nearly anything. Fix: add one specific criterion.
  • Feedback prompt lists multiple requirements → AI gives confusing nudges. Fix: one criterion only.
  • Sample response is the only valid answer → AI rejects equivalent correct code. Fix: add a second sample response that uses a different variable name or structure.
  • The question has no resolvable uncertainty → no productive struggle. Fix: ask for a prediction first, then the answer.
